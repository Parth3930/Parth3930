A cross-platform social app with a production-grade Rust backend.

- Built the mobile app in **Flutter** using **Riverpod**

## Featured Projects

### rust-claude-nano

A Rust reimplementation of Claude Code-style agentic coding workflows.

- Built in approximately **6,200 lines of Rust**
- Supports **10+ LLM providers**, including Anthropic, OpenAI, Gemini, and local models through Ollama
- Includes **MCP integration**, sub-agents, persistent memory, plugin architecture, and session management
- Maintains zero compiler warnings

### Recursive Thinking MCP

An MCP server for structured recursive reasoning in LLM workflows.

- Published as an npm-installable MCP server
- Enables iterative multi-step reasoning for MCP-compatible clients
- Built with **TypeScript**
- 4 GitHub stars

### PulseVote

A real-time polling application with AI-assisted community moderation.

- Built live polling with real-time data streaming
- Added an AI-powered Discord agent using **Mistral LLM**
- Stack: **Next.js**, **TypeScript**, **Pusher WebSockets**, **PostgreSQL**

### Realm

A peer-to-peer serverless AR collaboration platform.

- Built real-time gamified interaction using **WebRTC**
- Used **Astro** for frontend delivery
- Designed to work without a central server

### Avina Financial Marketplace

A FinTech marketplace for personalized financial product recommendations.

- Built with **Next.js**, **TypeScript**, and **Supabase**
- Integrated **Gemini AI** for personalized recommendations
- Added an AI chatbot for customer support and product guidance
- Designed responsive UI with **Material UI**
